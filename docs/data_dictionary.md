# Data Dictionary

## Mart layer

Одна строка = агрегированные температурные показатели за один день по одному городу.

| column | бизнес-смысл | единица | примечание |
|--------|-------------|--------|-----------|
| date | дата наблюдения | date | timezone Asia/Novosibirsk |
| city_id | уникальный идентификатор города | - | ключ |
| city_name | название города | - | |
| country_code | код страны | - | |
| temperature_mean | средняя температура за день | °C | среднее по часам |
| temperature_min | минимальная температура за день | °C | |
| temperature_max | максимальная температура за день | °C | |
| temperature_range | размах температуры | °C | max - min |
## ML / anomaly layer

Файл `docs/ml/anomalies_top.csv` содержит результат поиска аномальных температурных точек.

| column | бизнес-смысл | единица | примечание |
|--------|-------------|--------|-----------|
| time | время наблюдения | datetime | исходное время из normalized-слоя |
| date | дата наблюдения | date | используется для связи с дневной витриной |
| hour | час наблюдения | hour | 0-23 |
| temperature | температура | °C | анализируемая метрика |
| z_score | отклонение от среднего | std | вспомогательная оценка силы отклонения |
| iqr_lower_bound | нижняя граница IQR | °C | Q1 - 1.5 * IQR |
| iqr_upper_bound | верхняя граница IQR | °C | Q3 + 1.5 * IQR |
| distance_from_iqr_bound | расстояние от IQR-границы | °C | чем больше, тем сильнее выброс |
